# tenshi-folder-1k
TENSHI FOLDER 1K

📌 À propos du projet

TENSHI FOLDER 1K est une plateforme moderne permettant de créer et gérer une communauté de contacts WhatsApp avec un objectif de 1 000 membres.

Les utilisateurs peuvent s’inscrire en ajoutant leurs informations et leur numéro WhatsApp.

Les contacts enregistrés sont ensuite regroupés dans une liste que l’administrateur peut gérer et télécharger sous forme de fichier.

⸻

✨ Fonctionnalités

* 👤 Inscription des utilisateurs
* 📱 Enregistrement des numéros WhatsApp
* 🌍 Sélection du pays et de l’indicatif téléphonique
* 📂 Gestion centralisée des contacts
* 👑 Tableau de bord administrateur
* 📥 Téléchargement des contacts enregistrés
* 📱 Design responsive et compatible mobile
* 🔒 Gestion sécurisée des données

⸻

🛠️ Technologies utilisées

* HTML
* CSS
* JavaScript
* React / TypeScript
* Supabase
* Vercel

⸻

🚀 Objectif

L’objectif principal de TENSHI FOLDER 1K est de faciliter la création d’une communauté WhatsApp organisée pouvant atteindre 1 000 membres.

⸻

👑 Administration

L’administrateur peut :

* Voir les personnes inscrites
* Gérer les contacts
* Organiser les utilisateurs dans un seul dossier
* Télécharger la liste des contacts
* Créer un fichier de contacts pour WhatsApp

⸻

📱 Compatibilité

Le site est optimisé pour :

* iPhone
* Android
* Tablette
* Ordinateur
